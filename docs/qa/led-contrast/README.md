# LED 可读性调整

2026-10-25，用户要求照顾老年用户辨认数字：笔画加粗、有效数字加深、虚位更淡。

- 常规笔画从 9rpx 调到 13rpx，较长数字也按比例加粗；保留段与段之间的空隙。
- 有效数字使用 `#172B20`，相对 `#EAEFDF` 显示屏底色，对比度约 12.77:1（原约 8.78:1）。
- 未亮段使用 `#E6EBDC`，前导零使用 `#DFE6D4`，让实际数值更突出。
- 设备锁定时仍清晰显示数字，不随锁定降低数字对比；未绑定占位仍使用较淡横杠。
- 首页与触屏计数页共用 LED 组件，统一生效。

`328.png`、`108.png`、`0.png`、`1234567890.png` 为模拟器视觉样本，样本数字未写入业务记录。检查后已恢复真实数值和原浏览位置。79 项测试及 WXSS 编译通过。原 `docs/UI` 截图保留。
