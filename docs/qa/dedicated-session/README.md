# 一座专修与触屏计数区域调整

2026-10-25，按用户要求延续已确认的 UI 风格调整。

- 功课详情入口改为“一座专修”；只提供按时间、按次数。静坐功课只提供时间。
- 时间默认一炷香 35 分钟，另有两炷香 70 分钟、三炷香 105 分钟，可自定义正整数分钟。次数支持预设与自定义正整数，沿用上次成功开启的专修设置。
- 开始新一轮的确认说明：“本轮将重新计数，已累计的计数会保留。”取消不会修改记录或上次设置。
- 普通开始计数只保留确认标题，不附加小字，也不自动沿用专修提醒。
- 触屏计数区域由 360rpx 放大为 500rpx，短屏限制高度；移除底部“新一轮”及对应旧弹层。

验证：84 项 Node 测试通过；修改页面的 WXML / WXSS 使用微信官方编译器编译成功。微信开发者工具中检查默认 35 分钟、双模式、自定义 321 次、新一轮保留累计、实际点按计数及底部按钮移除；未发现运行异常。使用临时样本记录，验收后恢复原数据。未验证真实 BLE 硬件。
