## 本轮修复

1. **大愿快速连点会重复创建。** 新增同步提交锁和按钮禁用；校验失败或保存失败可重试，返回表单时恢复操作。新建、修改均有回归测试。
2. **专修达标后结束入口消失。** 达标仅提醒一次，保留专修状态与结束入口；明确结束后再退出专修，累计记录保留。重启后不重复提醒，新一座可正常提醒；静坐达标后仍可结束并结算座数。
3. “我的”页功课管理入口的旧说明改为“调整分组、顺序与删除功课”。

保留用户已确认的视觉风格，未覆盖 docs/UI 基准截图。

## 原记录保护

全部业务测试使用临时功课与记录。完成后核对功课、当日计数、补录、修正、归档、设备快照、大愿、设备和设置；本轮所属功课、数量与专修配置也与原记录一致。原恢复副本按原值还原，原导出文件逐字还原，临时文件与 API 替身已清理。
随后关闭并重新打开本项目，再次核对原记录与本轮数据。证明见 [冷启动核对](cold-start-proof.json) 和 [流程结果](results.json)。

## 测试边界与发布前剩余事项

- 原生确认框、年月选择器和开关在自动化中使用受控回调或事件。备份测试实际写入、读取和校验文件；文件发送与会话选择边界使用替身，未向任何联系人发送文件。手机微信的文件选择和发送仍需真机验收。
- 需在 iPhone 微信和 Android 手机微信中检查音效、震动、常亮、前后台计时、键盘和安全区，以及真实文件导入导出。模拟器结果不能替代这些体验。
- 微信登录、云同步仍按既定范围未实现；BLE 真机协议未实现。设备页验收覆盖未绑定与缓存设备未连接的失败处理，没有把模拟数据视作硬件联调通过。
- 当前仍将整份状态写入一个本地存储键。本轮未做多年记录容量或负载专项压测，长期容量改造应与后续云同步方案一起处理。
- 小程序后台主体、类目、隐私配置和微信审核结果不属于本机功能测试证明。
