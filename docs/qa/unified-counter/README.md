# 计数卡片与名称精简

2026-10-25，依据用户最新要求：

- 计数区仅显示“今日 数量 单位”，移除重复来源文字和“合计”。完整统计仍保留在功课列表等页面。
- 只启用一种计数时隐藏页签，两种均启用时显示双页签；两种均关闭的补录模式保持不变。
- 卡片与双页签共用白色背景、一个圆角外边框，不在卡片和页签之间画分割线。当前页签使用深色文字和短下划线。
- 长期大愿各入口只显示愿名，不额外拼接功课名；旧自动名称的“功课名 · ”前缀在显示时兼容去除，不批量改写存储。
- 新建大愿默认使用“目标数量与单位＋大愿”命名，手填名称不被后续修改目标或功课覆盖。

验证：81 项测试通过，WXML / WXSS 编译通过；模拟器确认计数区文案、双模式融合效果和两种单模式下的页签隐藏。截图为仅改变界面状态的预览，未修改计数或开关设置；结束后恢复真实显示。
