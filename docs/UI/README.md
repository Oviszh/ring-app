## 后续开发须保留

- 纸白背景 `#F6F7F3`、白色卡片、松墨主色 `#344F42`，正文 `#252E29`，细边线 `#E3E8E0`。
- 简洁、安静、严肃的整体气质；留白、字号与层级遵循截图，兼顾年长用户。
- 主要标题和功课名称使用宋体风格，正文使用系统无衬线字体；计数主数字使用七段 LED 组件。
- 首页计数卡片下方的「设备计数／触屏计数」页签，保持当前与卡片衔接的形态。
- 大按钮、清晰对比、圆角卡片、细分隔线，避免装饰堆叠和随意添加渐变、花纹、营销式文案。
- 新功能延续现有组件与 `miniprogram/app.wxss` 设计变量。未经用户明确要求，不整体改换视觉风格，也不以新截图覆盖本基准。

截图中的日期、数量、功课与开关状态仅用于呈现当时界面，不是固定业务数据或测试期望。

2026-10-25 用户要求强化底部三个标签的选中态：当前标签使用松墨色圆角底与白色图标，其余保持灰色。原基准截图保留，新效果见 `../qa/tab-selection/`。

同日用户要求提高 LED 可读性：笔画加粗、有效数字加深、虚位淡化；设备锁定时也保留有效数字的对比。后续沿用这一调整，参考 `../qa/led-contrast/` 中的视觉样本。

同日后续要求：计数卡片与双页签改为共用白色背景和一个圆角外边框，中间不分隔，当前页签用短下划线标识；单模式隐藏页签。计数区只显示“今日 数量 单位”，大愿名称不加功课前缀。最新效果见 `../qa/unified-counter/`，优先于原截图中对应的旧样式。

同日后续用户要求：详情页“新一轮与提醒”改为“一座专修”，时间默认一炷香 35 分钟，支持自定义；触屏计数页扩大触摸区域并移除底部“新一轮”。延续现有配色、字体和 LED 样式，参考 `../qa/dedicated-session/`。

同日用户进一步调整新建大愿的默认命名：以所选功课名称生成，如“念佛大愿”，填写目标后为“念佛1万声大愿”；切换功课时自动更新，用户手填名称后不再自动覆盖。已有大愿的名称和旧前缀展示兼容规则保持原样。

同日专修设置进一步按用户要求调整：按时间只提供“一柱香（35 分钟）／15 分钟／30 分钟／自定义”，选择自定义后显示输入框。详情页专修状态显示“一座专修已计 数量 单位”、时间模式的“距结束 分:秒”或次数模式的剩余数量，以及“结束本座专修”。视觉参考见 `../qa/session-status/`，优先于前一版专修截图。

同日用户继续调整：日历进入的补录页按“主修功课／常用功课”分成两组卡片，空分组不显示；指定功课的高亮保留在所属组内。新建长期大愿的默认名称去掉“大愿”后缀，如“念佛”或“念佛1万声”，切换功课或目标仍自动更新，手填名称与已有记录保持不变。

同日系统功课目录校订：添加功课页增加“常见／圣号／经文／咒语／祈愿礼忏／行持／全部”分类，所有分类入口直接可见；简介允许换行，相关咒语以汉字音译和藏文分行辨识，长咒明确标注起句。沿用现有纸白、松墨和大字号风格。新截图见 `../qa/practice-catalog/`，不覆盖原基准；内容校订规则及来源见 `../系统功课目录校订.md`。

同日用户继续调整：系统功课简介去掉“起句”标签，直接显示咒语，节选以省略号表达。功课管理页取消首页显示开关，每行改为“删除”按钮，确认后只从当前功课列表移除，保留历史记录。日历、补录明细、累计统计中的历史功课保留原名称，不再附加“（已删除）”。最新截图见 `../qa/manage-delete/`。
