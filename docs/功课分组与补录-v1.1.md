# 功课分组与快捷补录

2026-10-24，依据用户最新需求，在现有纸白与松墨视觉基准上调整功能，不覆盖 `docs/UI` 中的基准截图。

## 补录

- 增减补录弹层显示所选日期、所选功课的当前记录，并预览补录后合计；换日期、换功课及连续补录时更新参考值。
- 日历选中日期上方移除重复补录按钮，原“查看补录明细与撤销”改为“补录”，进入该日期的补录页。
- 补录页列出主修和常用功课，包括还没有记录的常用功课。点击数字填写希望达到的当日合计，确认或离开输入框后自动保存差额。
- 例如 328 改为 500，生成 +172；500 改为 200，生成 −300。每笔留存调整前后的数字，可展开和撤销；设备和触屏原始来源、本轮及提醒不改动。
- 此处“希望达到的合计”与“每日修行目标”不同；快捷补录不会修改每日目标或历史目标快照。
- 未改变数值不产生补录，确认和失焦不重复提交；无效输入恢复原值。编辑期间出现新计数时提示重新核对，不抵消新到达的计数。
- 当日总量不能为负；撤销正补录若会导致负数，需先撤销依赖它的负补录。
- 静坐按分钟补录。正在进行的当日计时需先结束，避免覆盖持续增长的时长；已结束计时可精确补录至目标分钟，原始秒数保留在原计时记录中。

用户明确要求的负补录沿用 v1.0 有符号补录规则，优先于旧定稿“补录只增、减少必须分来源修正”的限制。内部 `ring` / `phone` / `manual` 数据键、已有来源修正和统计公式继续兼容。

## 功课分类

- 管理页每项功课提供主修/常用选择，可直接双向切换；分类变化不创建新功课、不更换标识、不重置目标、本轮、排序或历史。
- 日历默认选择由“全部功课”改为“主修功课”，月历达标状态也只汇总主修。单项下拉仍包含常用功课，所选日期下方仍按主修、常用展示记录。
- 首页两个分类使用分开的卡片和分组标题；主修采用白卡与松墨标题，常用采用浅灰绿卡片，延续既有设计系统。

测试结果与本轮截图见 `qa/quick-entry/`；原始 UI 基准保持不变。
