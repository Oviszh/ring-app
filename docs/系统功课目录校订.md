# 系统功课目录校订

更新：2026-10-25。用户要求补全常用功课，并以准确的名称、别名与文本辨识信息替代泛化简介。

## 本轮范围

原库 51 条；新增 38 条，旧重复条目停显 1 条，当前可添加 88 项：圣号 10、经文 21、咒语 29、祈愿礼忏 18、行持 10。保留原有稳定标识，用户已添加功课、名称、每日目标、来源计数及历史记录均不迁移。

这是一份面向常见功课的可扩展目录，不把数量多少当作涵盖全部宗派、传承与版本的证明。

## 编校规则

1. 简介用于辨认文本：经文用经题，咒语用明确标注的起句或短咒，行持用记录对象。删除“净除业障 · 藏传加行”“加行之一”“长寿修法”等无法帮助识别具体文本的泛化标签，不增写功效承诺。
2. 长咒只摘取辨认所需起句，仅用省略号表示节选，不显示“起句”标签（用户后续要求）；不得拼接不同传本凑成全文。短咒展示所列来源中的公开文本。汉字音译存在传本差异，搜索兼容常见别名，不能把某一音译宣布为唯一读法。
3. 藏文独立一行，用系统藏文字体回退，不加拼音、不用图片代字、不截断单行。检索会归一化部分繁简字、空格和标点，不改写展示文字与存储记录。
4. 不把长咒、短心咒、礼赞文、祈请文当作同义名称。名字有关联并不等于文本相同。
5. 通用项目（如上师祈请文、皈依、回向）仅说明记录对象，不编造跨传承通用的正文；有明确名称的文本单独列项。
6. 下列来源是本轮使用的经题、公开文本或名称依据。`record` 仅表示本产品记录方式，`userNaming` 仅表示用户提供的群体称呼；二者不冒充经典依据。未经核对的字句不补写进简介。
7. 默认目标沿用应用的初始配置习惯，用户可调整；不将其解释为经典或各传承规定的每日数量。目录分类与用户的主修／常用分组相互独立。
