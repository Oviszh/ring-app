# 双计数入口 · v1.0.1

2026-10-24，依据用户最新要求恢复设备入口，覆盖此前“无设备入口”的界面范围。微信登录与云同步仍不做。

## 本轮功能

- 首页计数卡片下方使用设备计数、触屏计数两个页签。切换仅切换查看方式，不开始、结束或清零任何一侧本轮。
- 两侧分别保留当前功课、本轮数量与提醒，浏览功课互不影响。开始另一功课需单独确认。
- 设置提供两个独立开关：同时开启、仅设备、仅触屏、全部关闭四种组合。关闭仅收起入口，保留本轮和历史；全部关闭后使用手动填报。
- 功课详情遵循首页选择的计数方式；全部关闭时不显示计数操作。触屏入口关闭后，旧计数页不能继续点按或重开本轮。
- 无设备时显示“未绑定设备”和六位横杠，不展示虚构设备计数。已绑定但未连接时标明显示上次同步记录。
- 首页与触屏计数页采用原生七段 LED 组件，前导零弱化，兼容计时时钟和长数字，不依赖网络字体。
- 来源文案统一为“设备计数”“触屏计数”；内部保留 ring/phone 数据键，既有计数、修正、快照和备份继续兼容。
- 恢复我的设备、设备详情和绑定页面，正式配置禁止模拟设备。修正微信模块引用为显式的 BLE index 路径。

## 硬件边界

真实 BLE 适配器仍等待配套设备协议，尚未完成硬件连接和真机同步。绑定页明确提示设备尚未开放绑定，不使用模拟设备冒充真机。设备本地历史和领域操作保留。
