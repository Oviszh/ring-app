# 念佛计数 App —— 简易线段 UI（定稿 v1.5，与《App 需求与设计》对齐）

> 本文件包含全部页面的字符线段线框，供 UI 还原与开发使用。
> 配套文件：《App 需求与设计.md》。
>
> 图例：●=当前/达标 ○=非当前/有缺 ◐=部分 ▶=开始 ⟳=重新 ⏱=提醒目标
>       🔓/🔒=锁定状态 ✓=完成/开启 [ ]=按钮 ( )=可选项 ›=进入详情
>
> 结构：三 Tab 页 + 17 子页 + 3 弹层（共 20 页 + 3 弹层）。
> 主动作只有三个：点按（戒指/手机各自独立）、开启新一轮计数、填报。

---

## 0. 页面地图（跳转关系）

```
P1 今日(首页)
 ├─ ◀▶ 切换当前功课 / 锁定戒指（就地）
 ├─ [页签]手机计数 → P2
 ├─ [横幅]⏱提醒目标生效中 → P3（提醒目标所在功课）
 ├─ [行]我的功课 → P3 ｜ 配置› → P4 ｜ ＋添加功课 → P5
P2 手机计数(木鱼) → ⚙ P6 ｜ ← 回 P1
P3 功课详情 → 开启新一轮(方式=手机时跳 P2) ｜ 设置› P7 ｜ 大愿卡 P8 ｜ 历史› 日历Tab
P1' 日历 → 日期格 P9 → 功课行 P10 ｜ 大愿行 P8 ｜ ＋发大愿 P11
P1'' 我的 → 登录/注册 P17 ｜ 设备 P12-L → 单枚戒指 P12-A ｜ 绑定 P13 ｜ 大愿列表 P14 → P8/P11 ｜ 计数汇总 P15 ｜ 设置 P16
弹层：E1 提醒目标 ｜ E2 确认框 ｜ E3 填报
```

### P2-A 普通态（手机侧计数中）

```
┌───────────────────────────────┐
│ ←         手机计数          ⚙ │
│                               │

│                               │
│           128                 │

│                               │
│  今日累积 1,364 声｜今日目标 500声 │
│                               │
│       ╭─────────────╮         │
│      │    木  鱼     │        │ ← 整面大触摸区，轻触 +1
│       ╰─────────────╯         │    木鱼声 + 震动反馈
│          轻触 +1              │
│                               │
│  🔊 音效 [✓]     🎨 外观   ›  │
│  ⏱ 提醒目标生效中 · 剩 263 声   │ ← 仅手机侧有目标时显示（状态）；
│                               │    目标仅在"开启新一轮"时可设
│  [ ↩ 撤销一次 ] [ ⟳ 重新一轮 ] │
└───────────────────────────────┘
```

### P2-B 说明：手机与戒指各自独立

手机计数页只操作"手机侧"上下文：有自己的当前功课与本轮计数，
与戒指侧互不影响（戒指离线也在独立计数）。轻触永远 +1 到
手机本轮与今日累积，不存在"按了但数字不变"的情况。
两侧上下文分别在各自的「开启新一轮计数」时重置。

  弹 E2「该戒指已绑定其他用户。继续绑定将清空戒指内的
