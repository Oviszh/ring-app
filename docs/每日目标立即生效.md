# 每日目标立即生效

2026-10-25，用户明确要求替换原“每日目标次日生效”规则。

- 在功课设置中保存每日目标，立即更新今天的目标、进度和达标状态；提高、降低、取消目标均立即生效。
- 首页、功课详情、日历和补录页面统一读取今天的新目标；过去日期仍按其封存目标判断，不追溯更改。
- 修改时先完成跨日归档，只允许更新当前日期的目标快照。跨零点后昨天的目标保持封存，之后日期沿用最近保存的目标。

- 旧版已保存但未生效的目标，即使再次保存相同数值，也会更新今天的目标快照。
- 已更新设置页说明、保存提示及 `AGENTS.md`，以本规则取代旧文档中的次日生效约定。
